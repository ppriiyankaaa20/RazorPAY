Smart Global Payment Retry & 3DS Fallback Agent

An AI-powered payment recovery system that analyzes failed payments and recommends the best retry strategy.

Features

* Analyzes payment failures based on amount, country, and failure reason.
* Checks 3DS support for fallback decisions.
* Recommends whether and when to retry a payment.
* Provides retry strategy, retry delay, and maximum retry attempts.
* FastAPI backend with a simple HTML/CSS/JavaScript frontend.

Tech Stack

Python • FastAPI • JavaScript • HTML • CSS • SQLite
